# Application icon

The red sketch arrow and separate open target on a charcoal tile were generated with OpenAI ImageGen on 2026-10-17, using the earlier project mark as a visual reference. Transparent outer corners are retained. The mark is used for the native window, Windows executable and installer, macOS bundle, and Linux launcher.

The production source is `assets/app-icon.png`. `app-icon-256.png`, `app-icon.ico` (16, 24, 32, 48, 64, 128, 256 pixels), and `app-icon.icns` are mechanically resized/encoded copies, without redrawing or recoloring.

Generation direction: a simple matte charcoal rounded tile; a bold red hand-drawn arrow rising from bottom-left, stopping before a separate off-white open target; refined irregular pen edges; clear silhouette at small sizes; no text, glow, badge, or additional symbols. The target and arrow remain visibly separate.
