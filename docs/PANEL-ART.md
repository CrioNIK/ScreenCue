# Native dark text panels

The user selected **Dark Marker Strip**, option 1 from the second concept set on October 17, 2026. The native implementation keeps the dark rough silhouette, warm-white typography, and a restrained red brush accent. The text panel, arrow, and empty target outline have independent geometry. Text is not baked into artwork.

`assets/panel-brush.png` was generated by editing that selected concept with the built-in OpenAI image generation tool. It is a 2172 × 724 RGBA texture with transparent edges. It contains no text, controls, or application screenshot. The renderer sizes the background to native text layout, caches the rendered page, and keeps the panel stationary during drawing animation. IBM Plex Sans fonts and their provenance are recorded in [FONTS.md](FONTS.md).

Input is bounded to 100 heading characters and 16,000 body characters. Long text is paginated at full line boundaries within the selected display rather than reduced to illegible sizes. The agent chooses the page; the panel remains click-through. See [the panel API](INTEGRATION.md#text-panels).

The embedded fonts cover Latin and Cyrillic, including Ukrainian. A bounded text input is not a promise of universal script shaping, emoji rendering, or rich-text support. Panels use plain text.

No gray photographic canvas, no glow, gradients, shadows, words, symbols, numbers or red pixels. Keep whole rough silhouette inside canvas with modest transparent padding and no stray flecks detached faraway. It will be scaled to roughly400x120 native UI pixels; use broad cleanedge strokes that survive downsizing. Preserve selected style's flat2D refinedpunk markerfeel.
